- [ ] The measured `scrollHeight` is written to `style.height` without adding the borders, so a border-box textarea with a border settles 2px short and `overflow-hidden` clips the bottom of the last line — frontend/app/src/lib/useAutoGrowTextarea.ts:20 !p3
  Tailwind preflight sets `box-sizing: border-box`. The context textarea (TranslatePage.tsx:504) is `border border-line … resize-none overflow-hidden`. Past four lines, `fit` collapses to `auto`, reads `scrollHeight` = S (content + padding, borders excluded) and sets `height: Spx`, giving a padding box of S − 2px; the content is 2px taller and `overflow-hidden` hides the difference — visible on descenders and more so on CJK glyphs, which fill the em box, in a field meant for Spanish/Japanese context.
